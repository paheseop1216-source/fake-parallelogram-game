# 🕵️ 평행사변형 판별 작전

초등학교 4학년 수학 · 사각형 단원 · 정리 활동용 웹 게임 (두더지잡기형)

- 창문에서 튀어나오는 부품을 보고 진짜/가짜 평행사변형을 판별해 톡! (단계마다 60초)
  - 1단계 창문 공장: 가짜를 잡는다 (평행 표시 도움이 점점 줄어듦)
  - 2단계 미래 박물관: 규칙 반전 — 진짜를 잡는다 (직사각형·마름모·정사각형도 진짜)
  - 3단계 우주 정거장: 가짜를 잡는다 (진짜가 슬쩍 가짜로 변신, 모눈으로 확인)
- 마주 보는 두 쌍의 변이 모두 평행해야 진짜 평행사변형
- 실수하면 변을 늘여 "만나요!"로 이유를 보여 주고, 끝나면 헷갈린 부품을 색연필로 다시 확인
- 기록은 기기 브라우저에 이름별로 저장 (이어하기 · 처음부터 재도전 · 최고 기록)
